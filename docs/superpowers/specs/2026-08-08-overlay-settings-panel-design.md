# Overlay: заголовок ThisOne, drag-подсказки, панель Settings

Дата: 2026-08-08

## Контекст

`src/client/overlay.ts` рисует picker-панель (Shadow DOM). Сейчас:

- заголовок панели — "Select an element";
- при пикинге элемента вверху экрана висит фиксированная подсказка `pickHint`
  ("Click an element · Esc to close"), центрирована `left:50%`, не двигается;
- режим пути (`tree`/`root`) переключается кнопкой-иконкой рядом с самим путём;
- скриншот элемента всегда показывается, паддинг — константа `PADDING_PX=30`
  в `screenshot.ts`;
- нет заголовков-подписей над блоками пути/скриншота;
- скриншот рендерится асинхронно без индикации загрузки, путь — синхронно.

## Требования

1. `pickHint` можно перетаскивать по горизонтали правой кнопкой мыши, с
   ограничением по границам вьюпорта, положение запоминается в
   `localStorage`, у элемента есть `title`-тултип, объясняющий это поведение.
2. Заголовок панели меняется на `"ThisOne"`. Текст пустого состояния тела
   панели ("Select an element" в `renderEmpty`) не трогаем.
3. Между шапкой панели и телом — сворачиваемый блок **Settings**: строка с
   стрелкой (▸/▾) + текст "Settings", клик по строке — toggle. Состояние
   развёрнут/свёрнут — в `localStorage`, дефолт — свёрнут. Весь блок — мельче
   основного шрифта. Содержимое:
   - **Режим пути** — radio (`tree` / `root`), у каждого варианта иконка "?"
     с тултипом-объяснением режима (тексты — текущие подписи кнопки-тумблера).
   - **Показывать скриншот элемента** — radio да/нет, дефолт «да». Если
     «да» — под этим блоком появляется поле **паддинг** (число, px), дефолт 30.
     Кнопка-тумблер режима пути рядом с самим путём убирается совсем (единственная
     точка выбора — Settings).
4. Над блоком пути — заголовок "Path", над блоком скриншота — заголовок
   "Screenshot" (последний рендерится только если скриншот включён).
5. При клике по элементу путь показывается сразу. Если скриншот включён —
   сразу под путём показывается лоадер с текстом "Делаем скриншот", который
   заменяется на `<img>` по готовности (или на текст ошибки при неудаче).
   Если скриншот выключен — блок скриншота не рендерится вовсе.

## Архитектура / файлы

Новые стор-модули (по образцу `path-mode-store.ts` — try/catch вокруг
`localStorage`, JSON, дефолты на ошибке парсинга):

- `src/client/pickhint-store.ts` — `loadPickHintOffsetX(): number | null`,
  `savePickHintOffsetX(x: number): void`. Хранит абсолютный `left` (px), не
  проценты — клампится от текущей `innerWidth` при применении/resize.
- `src/client/settings-store.ts` — `loadSettingsExpanded(): boolean`
  (дефолт `false`), `saveSettingsExpanded(expanded: boolean): void`.
- `src/client/screenshot-store.ts` — `loadScreenshotEnabled(): boolean`
  (дефолт `true`), `saveScreenshotEnabled(enabled: boolean): void`,
  `loadScreenshotPadding(): number` (дефолт 30, отрицательные/NaN → дефолт),
  `saveScreenshotPadding(padding: number): void`.

Изменения в `screenshot.ts`:

- `PADDING_PX` остаётся дефолтной константой, но `captureElementScreenshot`
  принимает третий необязательный параметр `padding = PADDING_PX`.

Изменения в `overlay.ts`:

- `.title` → `"ThisOne"`.
- Новый DOM-узел `.settings` между `header` и `body`: строка-тоггл
  (arrow-icon + "Settings") и контейнер с radio-группами. Рендерится один
  раз в `ensureMounted`, не пересоздаётся при каждом пике.
- Убрать `.path-mode-toggle` из `path-row` в `renderSelection`; режим пути
  теперь берётся из состояния, изменяемого radio-группой в Settings —
  при смене радио вызывается перерендер текущего пути (если пик открыт и
  элемент выбран).
- `pickHint`: `mousedown` (button 2) запускает драг с подавлением
  `contextmenu`, аналогично существующему `onTargetDragStart` для
  `targetBtn`. Клампится `[0, innerWidth - offsetWidth]`. `title` со
  статичным текстом подсказки.
- `renderSelection`: секция "Path" рендерится сразу; секция "Screenshot"
  (заголовок + лоадер → img) рендерится только если
  `loadScreenshotEnabled()` истинно; паддинг берётся из
  `loadScreenshotPadding()`.

## Тестирование

Unit-тесты (vitest, по образцу существующих тестов сторов):

- `pickhint-store`: round-trip, отсутствие значения → `null`, битый JSON → `null`.
- `settings-store`, `screenshot-store`: round-trip, дефолты, невалидные
  значения (отрицательный паддинг, NaN, не-boolean) → дефолт.
- Кламп-функция для `pickHint` offset: значение больше `innerWidth -
width`, отрицательное значение, `resize` после сохранённого значения.
- `captureElementScreenshot`/`paddedCropRect` с нестандартным паддингом
  (0, большое значение, отрицательное — уже клампится на уровне стора, но
  сама функция должна не падать).

E2E / визуально: скриншот до/после панели (косметика в основном, но задета
логика — режим пути, включение/выключение скриншота), плюс happy-path
клика по элементу с обоими состояниями скриншота (on/off) и с драгом
pickHint.
