# @si-ic/thisone

Alias package. Installing `@si-ic/thisone` gives you exactly [`vite-plugin-thisone`](https://www.npmjs.com/package/vite-plugin-thisone) — point at any element in your Vite dev preview and hand your AI agent its exact source location and a screenshot.

```bash
npm i -D @si-ic/thisone
```

```ts
import thisone from "@si-ic/thisone";
```

Full documentation: https://github.com/SI-IC/thisone
