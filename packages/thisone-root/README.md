# thisone

Alias package. Installing `thisone` gives you exactly [`vite-plugin-thisone`](https://www.npmjs.com/package/vite-plugin-thisone) — point at any element in your Vite dev preview and hand your AI agent its exact source location and a screenshot.

```bash
npm i -D thisone
```

```ts
import thisone from "thisone";
```

Full documentation: https://github.com/SI-IC/thisone
